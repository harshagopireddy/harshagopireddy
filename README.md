## 📌 Featured Project

### 🌾 Kisan Market — Farmer-to-Customer Marketplace

A full-stack web application that connects farmers directly with customers, eliminating middlemen and ensuring fair pricing.

**Tech Used:**
- Backend: Spring Boot 4.1, Java 21, Spring Security + JWT, Spring Data JPA
- Frontend: React 19, Vite, React Router 7, Axios
- Database: MySQL 8

**Features:**
- JWT-based Authentication & Role-Based Access Control (Farmer / Customer / Admin)
- Product management with CRUD operations
- Order placement with stock validation
- Admin dashboard with user, product & order management
- Responsive frontend with separate views for each role

🔗 [GitHub Repo](https://github.com/harshagopireddy/kisan-market)
